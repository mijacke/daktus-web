# Daktus Web

Oficiálny web štúdia Daktus (daktus.sk).

## Stack

Nuxt 3 (Vue), GSAP a Lenis pre animácie.

## Deploy

Hosting Netlify. Každý merge do vetvy master sa automaticky nasadí na produkciu, pull requesty dostávajú deploy preview.

## Stav

Na produkcii je zatiaľ dočasná coming-soon stránka (`index.html` v koreni repa, publikovaná cez `netlify.toml`). Nuxt scaffold pribudne neskôr a nahradí ju.
